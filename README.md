# スカイライン・テクノロジー 企業サイト

架空のソフトウェア企業「スカイライン・テクノロジー株式会社」のコーポレートサイトです。
掲載している会社情報・数字・人物などはすべてフィクションです。

## サイトの概要

高層ビルの「フロア案内板」をモチーフにした1ページ構成のサイトです。各セクションを1つのフロアに見立て、上の階から順に降りていく構成になっています。

| フロア | セクション | 内容 |
|---|---|---|
| — | ヘッダー・お知らせ欄 | ナビゲーションと最新のお知らせ |
| — | トップ | キャッチコピー、フロア案内、夜景のアニメーション |
| 38F | 事業内容 | SkyOps・Horizon BI・受託開発の紹介 |
| 37F | 数字で見る | 導入企業数・稼働率などの実績 |
| 36F | 開発プロセス | 受託開発の4つの段階 |
| 35F | お知らせ | ニュース一覧 |
| 34F | 会社概要 | 会社情報と本社アクセス |
| 33F | 採用情報 | 募集職種・制度・社員の声・選考の流れ |
| 1F | お問い合わせ | 入力フォーム（デモのため送信はされません） |

ライトモード・ダークモードとスマートフォン表示に対応しています。

## ファイル構成

```
company-site/
├── index.html        … ページ本体（HTML）
├── css/style.css     … スタイルシート
├── js/main.js        … 夜景の描画、フォームの入力チェック、応募ボタンの処理
└── .claude/          … Claude Code の設定（変更前の自動バックアップ）
```

ビルドやインストールは不要です。HTML・CSS・JavaScript のファイルだけで動きます。

## ブラウザで開く手順

### 方法1：エクスプローラーから開く

1. エクスプローラーで `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Microsoft Edge や Google Chrome など）でサイトが表示されます。

使いたいブラウザを選ぶ場合は、`index.html` を右クリックして「プログラムから開く」からブラウザを選んでください。
開いているブラウザのウィンドウに `index.html` をドラッグ＆ドロップしても表示できます。

### 方法2：コマンドから開く

PowerShell またはコマンドプロンプトで、このフォルダに移動して次のコマンドを実行します。

```powershell
start index.html
```

### 表示についての注意

- 文字のフォントは Google Fonts から読み込んでいます。インターネットに接続していない場合は、パソコンに入っている代わりのフォントで表示されます。
- ファイルを編集したあとは、ブラウザを再読み込み（`F5` キー）すると変更が反映されます。
